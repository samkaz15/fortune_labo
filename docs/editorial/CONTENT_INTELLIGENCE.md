# Content Intelligence

Version: 0.2.0。Editorial Foundationの方向性は承認済み。SEO policy、商品提供、個別記事の公開は別途承認を必要とする。

本書と [機械可読版](content-intelligence.json) は、非公開資料から作成した短い編集上の要約である。原文、調査上の数値・順位、個人情報、非公開の商品企画詳細は公開しない。根拠は不透明なSource IDで [Provenance](sources/provenance.json) に結び付ける。要約は実測成果や需要量を示さない。

| Genre | 読者の中心的な課題 | FREEの役割 | PREMIUM候補の追加価値 |
| --- | --- | --- | --- |
| 総合運・月運 | 時期に応じた行動の整理 | 考え方と小さな実践 | 個人条件を踏まえた計画 |
| 恋愛 | 関係に応じた行動の選択 | 悩みを整理する手がかり | 関係固有の行動案 |
| 結婚 | 将来に向けた条件の確認 | 話し合う観点 | 二人の条件に沿った検討 |
| 仕事・キャリア | 働き方の選択肢の比較 | 悩みと準備の整理 | 条件別の実践計画 |
| 金運 | お金と生活習慣の見直し | 支出や習慣の把握 | 制約に合わせた習慣計画 |
| 健康・生活習慣 | 無理のない生活の調整 | 生活を振り返る観点 | 継続可能な生活計画 |
| 自己理解・才能 | 自分に合う環境の検討 | 傾向を考える入口 | 個人条件を整理した解釈 |
| 神社・参拝 | 参拝情報と目的の整理 | 確認済み情報 | 目的と条件に沿った計画 |
| 方位・旅行・引越し | 日程や行き先の検討 | 基本的な考え方 | 個別条件に沿った検討 |
| 相性 | 二人の違いと接し方の理解 | 解釈の基本 | 関係に応じた会話の検討 |
| 霊視・個別相談 | 相談事項の具体化 | 相談の準備 | 確認済み提供者による相談 |

共通の編集判断とジャンル固有のInsightを区別する。根拠のない潜在ニーズ・再訪目的・CTAはnullであり、一般的な説明で埋めない。上表のPREMIUMは価値の候補で、実在する商品の仕様や販売の承認ではない。分類体系は [Genre Taxonomy](GENRE_TAXONOMY.md)、アクセス判定は [FREE / PREMIUM Rules](FREE_PREMIUM_RULES.md) を参照する。

A07はジャンルのInsight、既存記事との重複、A06の検索意図と制作条件、利用可能な実測値からBriefを作る。A08はそのBriefを変更せず [Article Production Rules](ARTICLE_PRODUCTION_RULES.md) に従う。調査にジャンルが存在するだけでは、A06のTierや実体験要件を満たしたことにならない。

医療・金融の結果、他人の心理、未来の成否を占いで保証しない。神社記事には既存A06どおり実訪問記録と許諾が必要であり、不足する見立てや実体験をAIで創作しない。

`topic_candidates` は上記の公開用要約から作成した編集候補である。検索需要や正式A06 opportunityではない。各ジャンルに基礎的な問いのFREE候補を一つ登録し、未確認のkeywordはnullとする。既存記事との比較結果は新規制作の許可を意味しない。
