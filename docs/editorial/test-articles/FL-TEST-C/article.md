# 転職を考える人の90日ワーク――条件、試行、見直しを一冊に残す

仕事を変えたい理由は書けたけれど、その後の準備がつながらない。このワークでは、条件を記入し、調べた情報と試した結果を残し、次に何を確かめるかを決めていきます。最後に作るのは、応募した件数の一覧ではなく、自分の条件と未確認事項を添えた判断メモです。

無料の整理記事は、変えたいこと、残したいこと、次に確かめることを見つけるために使えます。ここではその先を、条件シート、試行メモ、比較表として繰り返し使える形にします。自分で事情を書き込むワークであり、個別鑑定、適職の判定、転職の成功を約束するサービスではありません。90日は作業を整理するために置いた期間で、効果が実証された日数や退職の期限ではありません。

## 最初に、守りたい条件と計画の上限を決める

始める前に、今の生活でこの準備に使える時間を確認します。毎晩取り組む予定が合わなければ、休日の一度だけでも構いません。作業時間だけでなく、今は進めないことも書いてください。「今月は応募せず、条件を調べるところまで」と決めるなら、それが今回の計画の範囲です。

次のシートは、説明用の架空の記入例です。実際の相談者や成功例を紹介するものではありません。自分の欄を埋めるときは、完成した言い方に整えるより、気になっている場面を残すことを優先してください。

| 条件シート | 架空の記入例 | 自分の記入欄 |
| --- | --- | --- |
| 変えたい場面 | 夕方に翌朝締切の依頼が来る | いつ、何に困るかを書く |
| 残したい仕事 | 情報を集めて資料にする仕事 | 続けたい作業を書く |
| 今回使える時間 | 休日に一度、短く取り組む | 実際の予定に合わせる |
| 今はしないこと | 条件を確認する前に退職を決める | 自分の判断の境界を書く |

「残したい仕事」が書けなければ、無理に長所へ言い換えなくて構いません。「次もやってよい仕事」として一つ挙げる方法もあります。空欄は不足の印ではなく、これから確かめる問いとして扱います。

## 1〜30日：経験を、確かめられる問いにする

最初の期間は、一つの仕事を取り上げて、依頼されたこと、自分が進めた部分、次も続けたい部分を記録します。たとえば架空の記入例では、「資料を作った」から一段具体的にして、「複数の説明資料から必要な情報を拾い、読む順番を並べ直した」と置けます。仕事の名前だけで比較しないための作業です。

続けたい部分が見えたら、働き方への希望とは別の行に書きます。「情報を整理する作業」と「依頼の予定が早めに分かること」は、候補を見る際にそれぞれ確かめる項目です。片方が合いそうだからといって、もう片方も合うと埋めないでください。

ここまで書けたら、募集内容を一件選んで読み、条件の横に「記載あり」「未記載」「確認が必要」を残します。情報を読むだけで分かる範囲と、問い合わせ等が必要な範囲が分かれたところで一度区切ります。候補が見つからなければ、自分の経験の記録をもう一つ増やすところに戻れます。

この期間の終わりに見直すのは、予定した作業量よりも、問いが具体的になったかです。「自分に合う会社を探す」から「依頼の締切は誰と調整できるのかを確かめる」に変わっていれば、その問いを次の期間へ持っていきます。まだ言葉にならない部分は、判断を保留する理由として残しましょう。

## 31〜60日：一つ試して、結果の読み方を決める

次は、残った問いの中から一つを選び、情報を増やす行動を決めます。職務経歴の一項目を書く、募集の説明会を調べる、現職で相談できる範囲を整理するなど、今の条件で実行できるものにしてください。面談や応募そのものを必須にはしません。

試す前に「今回何が分かればよいか」を書くのが、このワークの記録上のルールです。仮に、自分が担当した作業を説明できるか確かめたいなら、文章を一項目作り、担当範囲が読み取れるかを見直すところまでを一回の作業にします。結果を見てから目的を増やすと比較しにくいため、追加で気になった点は次回の問いに分けます。

| 試行メモ | 架空の記入例 |
| --- | --- |
| 確かめる問い | 自分が担当した部分を説明できるか |
| 今回したこと | 資料を整理した作業を一項目にまとめた |
| 確認できたこと | 調べた情報と並べ方を書き分けられた |
| まだ分からないこと | 担当していない作業との境界が伝わるか |
| 次に変える部分 | 最初に自分の担当範囲を一文加える |

文章を見てもらう場合は、相手と確認できる範囲を選び、公開できない業務情報や他人の個人情報を持ち出さないようにします。見てもらう機会がなければ、自分で読み返して未確認のまま残して構いません。他人に確認していない内容を「評価された」と書き替えないでください。

取り組めなかった週には、遅れを埋める作業を増やす前に、時間がなかったのか、作業の意味が曖昧だったのかを一行残します。再開時にはその一行と前回の問いを読み、同じ作業を続けるか、範囲を小さくするかを選べます。中断しても使える記録を作ることが、継続ワークの用途の一つです。

## 61〜90日：比較表から次の期間を選ぶ

最後の期間では、最初の条件シートと、その後に確かめた情報を並べます。新しい候補を増やすだけでなく、現職で調整を考える案も比較に置けます。まだ候補がない場合は、「何が分かれば比較できるか」を書く表として使ってください。

| 確かめる条件 | 現職で調整する案 | 別の仕事を探す案 |
| --- | --- | --- |
| 続けたい作業を担えるか | 確認した内容と確認日 | 募集内容と確認日 |
| 依頼の予定を相談できるか | 相談できる範囲、または未確認 | 記載内容、または未確認 |
| 次に必要な情報 | 誰に何を確かめるか | どの情報を探すか |

表に空欄が残ったら、ほかの欄のよさで埋めず、「未確認」と書きます。たとえば仕事内容に関心が持てても、予定の調整方法が分からなければ、その条件の判断は保留です。この表では合計点を作らず、守りたい条件と未確認の点を見落とさないために比較します。

終わりの判断メモには、「今選ぶこと」「その根拠」「残っている問い」「次に見直すきっかけ」を書いてください。応募を検討する、現職で相談を続ける、もう一度条件を整理するという結論を置けます。90日目が来たことだけを、転職や退職の理由にする必要はありません。

使い始める際は、条件シートの一行だけ記入して、次に開く日を決めてみてください。基本の条件整理に戻りたいときは、関連する無料記事「転職したいのに動けないとき、最初に確かめる三つのこと」も使えます。記録を増やすことより、自分が次に何を確かめるのか分かる状態を、その都度作り直していきましょう。
