## 5. バッチの選定根拠

2026年9月時点の季節性（positioning §7）:

| 窓 | 状態 |
| --- | --- |
| 七五三 | **いま**（9月上旬までに出す窓） |
| 年間見通し（2027年） | 10–12月に需要形成、10月下旬公開 → 9月は素材の仕込み期 |
| 初詣 | 11月上旬公開 → 9月は着手前 |

したがって本バッチは「七五三の時期の投稿」＋「年間見通しへの助走」＋通年の Tier B / Tier C で構成した。

## 6. 一人称の記述についての注意（重要）

本バッチの投稿は占術師の一人称で書かれている。文中の「対面を続けている」「ご相談で
多いのは」といった**自分の実務についての記述は、実質的に事業ファクト**であり、
AI が確定させてよいものではない。

したがって公開前に、占術師本人が全文を読み、

- 実際の実務と食い違う記述がないか
- 自分の言葉として発してよい内容か

を確認すること。**表現の調整ではなく、事実確認のゲート**として扱う。
見立てを外した事例など、本人にしか書けない箇所は空欄（プレースホルダ）のまま渡している。

## 7. 公開前チェックリスト

各投稿について、上から順に確認する。1つでも通らなければ公開しない。

1. [ ] Tier D テーマを含んでいない（positioning §5）
2. [ ] 恐怖訴求がない（「〜しないと運気が下がる」等）— **タイトル・冒頭2行も対象**
3. [ ] 効果保証がない（「〜すれば叶う」等）
4. [ ] 神社の効果比較・ランキングがない
5. [ ] 医療・法律・金銭の効果を示唆していない
6. [ ] 捏造した体験談・実績・お客様の声がない
7. [ ] 主観が主観として書かれている（`私の見立てでは` 等）
8. [ ] 免責文が入っている（または導線がある）
9. [ ] 神社に触れる場合、参拝記録 ID と参拝日に紐づいている
10. [ ] 写真の掲載許諾が確認済み
11. [ ] プレースホルダが全て実値に置換されている（`{{` が残っていない）
12. [ ] 置換後に文字数を再カウントした（特に X）
13. [ ] `fact_check: required` の投稿は確認済み
14. [ ] 年間見通しに触れる投稿は、翌年の振り返りがカレンダー登録済み（rules §3-3）
15. [ ] 占術師本人が全文を確認した（§6）
16. [ ] 人間の公開承認を得た（`AGENTS.md`）

`{{` の残存は機械的に検出できる:

```sh
grep -rn '{{' fortune_labo/content/sns/drafts/ | grep -v README
```

## 8. 各ドラフトのステータス表記

- `status: draft` — 制作済み・QA 未通過
- `status: blocked` — 一次情報または事業ファクト待ちで制作不可
- `fact_check: required` — 一般的な作法・慣習に触れており A29 Fact-Check Agent の確認が必要
