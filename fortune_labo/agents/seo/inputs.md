# SEO Agent — Inputs

## From Analytics Agent

| Input | Source | Phase |
| --- | --- | --- |
| Query performance (clicks, impressions, CTR, position) | GSC Search Analytics API | 2 |
| Index coverage / crawl errors | GSC URL Inspection + Index API | 2 |
| Core Web Vitals field data | GSC / CrUX | 2 |
| Sessions, engagement, landing pages by channel | GA4 Data API | 2 |
| Booking conversions with first-touch attribution | GA4 + booking system | 3 |
| Branded vs non-branded query split | GSC (derived) | 2 |

## From the human practitioner (irreplaceable)

| Input | Why it cannot come from anywhere else |
| --- | --- |
| Visit notes, photographs, impressions | The moat itself |
| Divinatory basis for annual judgments | Only the practitioner holds the method |
| Availability and travel capacity | Bounds all Tier A planning |
| **Real client questions and phrasing** | Highest-value keyword source in the system |
| Shrine photo permission status | Legal gate |

Client questions outrank keyword tools. They are the literal language of people
who already paid.

## From WordPress

Site structure, published URLs and metadata, internal link graph, publish and
update dates, taxonomy, template structure. Read-only in Phase 1–2.

## From Strategy Agent

Business objectives and current priority, capacity constraints, pricing and
service changes, approved and rejected directions.

## Availability by phase

| Phase | Available | SEO Agent operates on |
| --- | --- | --- |
| **1 — Now** | Repo docs, manual SERP observation, human input, public competitor data | Manual analysis, keyword register, visit plans, technical audit specs |
| **2** | GSC + GA4 read APIs | Automated diagnosis, weekly loop |
| **3** | Booking data + attribution | Full Tier 1 KPI, true prioritisation by revenue |

**Phase 1 is fully operational.** SEO Agent is not blocked on API access — it
produces keyword strategy, visit plans, and technical specs from human input and
manual observation from day one.
