# A11 — Actual asset QA prompt

実ファイルを開き、plan、該当H2、Draft、Visual Identityと比較する。promptだけを見て品質合格にしない。

記事との関係、図の向きや比較の意味、本文と矛盾する表現、文字の欠けや誤字、読みやすさ、不要な装飾、実在対象の誤認、生成物の開示、alt/caption、色・光・質感の一貫性を確認する。写真が事実根拠として必要なら、実写由来と利用権の記録を照合する。

native図はSVG masterとPNG派生を両方確認し、文字内容と描画が一致するか見る。自動hash検証は内容の一致や視覚品質を保証しない。NO_IMAGEの節は、本文・表だけで十分という理由が妥当か確認する。

各image_idに判定と根拠、修正点、残課題を残す。未生成・読めない・参照不足を合格にしない。A11/モデルの視覚確認を人間の公開承認と表現しない。
