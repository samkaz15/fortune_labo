# Script Agent (A10-SC)

動画台本の企画・執筆エージェント。
対象は **TikTok / Instagram Reels / YouTube Shorts / YouTube 本編**。

> **最初に [`positioning.md`](./positioning.md) を読んでください。**
> このディレクトリの他のすべてを制約します。

## このエージェントは何か

**台本を書きます。それだけです。** 撮影も編集も投稿もしません。

```
   A06 SEO ── 季節暦・参拝計画     占術師 ── 参拝記録・撮影素材・収録時間
   A02/A29 ── 検証済みの史実             ── 撮影許諾（動画・商用）
          │                                    │
          └──────────────┬─────────────────────┘
                         ▼
              A07 Content Strategy（テーマ承認）
                         ▼
          ┌──────────────────────────┐
          │  SCRIPT AGENT (A10-SC)   │
          │  テーマ→尺→フック→台本→  │
          │  ショットリスト→事実分類  │
          └──────────┬───────────────┘
                     ├──────► A29 Fact-Check
                     ▼               │
              ★撮影前チェック ◄───────┘
                     ▼
                A28 QA Agent
                     ▼
            人間承認（台本）  ← 1回目
                     ▼
                撮影（人間）
                     ▼
           A11 Creative（編集・サムネ）
                     ▼
            人間承認（完成尺）  ← 2回目
                     ▼
                投稿（人間）
                     ▼
              A18 Analytics
                     ▼
            SCRIPT AGENT（解釈）
```

**人間承認が2回**あります。撮ってから内容の問題が見つかると撮り直しの
コストが丸ごと無駄になるため、台本の段階で1回止めます。

## 設計上の要点

**1. 撮れない台本は書かない。**
テキストなら書けば出せますが、動画は撮れなければ0本です。だから
「撮影可否の確認」が制作手順の最初に来ます。現地撮影を含む台本は、
参拝記録IDと**動画・商用**の撮影許諾が揃うまで撮影に進みません。
`video_script.schema.json` がこれを構造で強制します。

**2. 写真の許諾は動画の許諾ではない。**
多くの社寺が静止画と動画、私的利用と商用利用を分けて規定しています。
`permission_status` に `confirmed_photo_only` があるのはこのためで、
その値では現地撮影に進めません（`rules.md` §4.1）。

**3. AI生成映像には境界がある。**
神社や参拝の情景を生成するのは一次体験の捏造で禁止です。図解と抽象イメージは
可。`ai_generated_ratio` が過半なら一次情報が薄く、一行テストに落ちます
（`positioning.md` §4）。

**4. 冒頭3秒を3層で設計する。**
視覚・音声・テロップ。スキーマが3つとも要求するので、どれかを忘れた台本は
出力できません。

**5. 無音で成立させる。**
多くの視聴者は音を消しています。`silent_viable: false` は検証で警告が出ます。

**6. 事実の分類は執筆より前。**
動画は撮影コストが高く、事実が崩れると台本ごと捨てることになります。
テキストなら1文直せば済むところが、動画では撮り直しです。

**7. 指標は3秒維持率とプロフィール遷移。**
再生数は Tier 3（診断のみ）。100万再生でプロフィール遷移ゼロは失敗です。

**8. 成果は「書いた本数」ではなく「撮れた本数」。**
`shoot_completion_rate` が 0.8 を切ったら、台本が現実から離れています。

## スキーマと検証

| スキーマ | 単位 | 渡す先 |
| --- | --- | --- |
| `video_script.schema.json` | 台本1本 | A28 QA → 人間 → 撮影 |
| `video_fact_check_request.schema.json` | 検証が要るクレーム | A29（A28経由） |
| `video_performance.schema.json` | 実測値 | A18 ⇄ 本エージェント |

```sh
python3 fortune_labo/agents/sns/script/schemas/validate.py
```

スキーマ単体では見られない**項目間の整合**を `validate.py` が検査します。

- 文字数と想定尺の整合（325字/分）
- 想定尺がフォーマットの枠に収まるか
- ショットリストの時間が連続しているか（飛び・重なり）
- ショットリストの総尺と想定尺の整合
- 現地撮影の有無と撮影許諾・参拝記録の整合
- AI素材比率の申告値と実測値の一致
- 無音で成立するか

実例2件で検証済み。60秒枠に450字、ショットの飛び、許諾不備を仕込んだ
負のテストも通しています。

## 現状の制約（重要）

| 必要なもの | 現状 |
| --- | --- |
| **参拝記録** | **0件** |
| **撮影許諾フロー（動画・商用）** | **未整備** |
| 本人収録の環境・時間 | 未確定 |
| 事業ファクト | `{{placeholder}}` |
| 標準免責文 | 未承認 |

**つまり今書けるのは、本人収録と図解だけで完結する台本（Tier V-B / V-C）
に限られます。** Tier V-A（実写・moat）は1本も書けません。

これは制約であって障害ではありません。暦・節句・日本文化の解説は
本人収録と図解で成立します。`examples/VS-0001.json`（重陽の節句）が
その実例です。`examples/VS-0002.json` は逆に、参拝記録が無いと
どこで止まるかを示す `blocked` の実例です。
