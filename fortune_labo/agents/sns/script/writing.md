# Script Agent — 台本の書き方

`rules.md` が禁止事項、この文書が「良い台本とは何か」です。

---

## 1. 話し言葉で書く

台本は**読み上げるもの**です。書き言葉のまま渡すと、収録で必ず詰まります。

| 書かない | 書く |
| --- | --- |
| 九星気学においては | 九星気学では |
| 〜であると考えられています | 〜と言われています |
| 本日は〜についてご説明します | 今日は〜の話をします |
| 重陽の節句とは、五節句の一つであり | 重陽の節句。五節句の最後です |

**声に出して読んでください。**読みにくければ台本が悪いのであって、
読む人が悪いのではありません。

漢字の読みが割れる語（寒川／大祓／庚申）には**ルビを振ります**。
収録現場で止まる原因の第1位です。

---

## 2. 冒頭3秒 — 3層で設計する

短尺の成否はここで決まります。台本には必ず3層すべてを書きます。

```
0:00-0:03
  視覚: 拝殿の鳥居をくぐる主観映像
  音声: 「ここ、江戸時代は海の底でした」
  テロップ: ここ、江戸時代は海だった
```

| 層 | 役割 | よくある失敗 |
| --- | --- | --- |
| **視覚** | 止める | 顔アップから始める（誰か分からない人の顔は止まらない） |
| **音声** | 引く | 自己紹介から始める |
| **テロップ** | 無音対応 | 音声と一字一句同じにする（読む速度が合わない） |

**テロップは音声の要約であって、書き起こしではありません。**

### フックの型

| 型 | 例 |
| --- | --- |
| 意外な事実 | 「ここ、江戸時代は海の底でした」 |
| 前提の否定 | 「お賽銭、金額に意味はありません」 |
| 順序の逆転 | 「運気が落ちてるとき、財布より先に変えるものがあります」 |
| 具体の日付 | 「9月9日。五節句の最後の日です」 |
| 行為の提示 | （黙って手水舎で清める映像）→ テロップ「正しい順番、知ってますか」 |

最後の型は**音声なしで始める**もので、無音視聴と相性が良い。

### フックの禁止（`rules.md` §2 と重複するが、ここが一番使われる）

- 「知らないと損します」「やらないと運気が下がります」— 恐怖訴求
- 「絶対に運気が上がる方法」— 効果断定
- 「99%の人が知らない」— 根拠のない数字
- 回収されないフック — 3秒で釣って本編で答えない

---

## 3. 無音で成立させる

多くの視聴者は音を消しています。**テロップと画だけで意味が通るか**を
必ず確認してください（`positioning.md` §8）。

- 重要な情報は必ずテロップに入れる
- 「これ」「それ」で指さない。画に映っていないものを指示語で呼ばない
- 数字・固有名詞は必ずテロップ

---

## 4. テロップ設計

| 項目 | 目安 |
| --- | --- |
| 1画面の文字数 | 全角 13〜20字 × 最大2行 |
| 表示時間 | 1画面あたり 1.5〜3秒 |
| 位置 | 画面中央〜やや上（下部はUIに隠れる） |
| 強調 | 1画面に1箇所まで |

テロップが3行以上必要なら、それは**1つの文に情報を詰めすぎ**です。分けてください。

---

## 5. 間（ま）

台本には**間を書きます**。書かないと詰め込まれます。

```
「ここ、江戸時代は海の底でした」
（1秒・鳥居を見上げる）
「今は住宅街のど真ん中です」
```

短尺で間を取れるのは、フック直後と結論直前の2箇所くらいです。
長尺では章の切れ目に必ず入れます。

---

## 6. ショットリスト

台本と対になる成果物。**何を撮るか**を時系列で並べます。
どう撮るか（構図・光・色）は A11 Creative Agent の領域です。

| 時間 | 画 | 音声 | テロップ | 素材 |
| --- | --- | --- | --- | --- |
| 0:00-0:03 | 鳥居をくぐる | 「ここ、江戸時代は海の底でした」 | ここ、江戸時代は海だった | 現地撮影 |
| 0:03-0:08 | 拝殿の引き | 「寒川神社。相模国一之宮です」 | 寒川神社／相模国一之宮 | 現地撮影 |
| 0:08-0:20 | 古地図の図解 | 「このあたりは入り江で…」 | — | 図解（AI可） |

`素材` 列は4種類のみ：

| 値 | 意味 |
| --- | --- |
| `現地撮影` | 実際に行って撮る。**参拝記録と撮影許諾が必要** |
| `本人収録` | 占術師が話す。スタジオ・自宅可 |
| `図解` | 資料・アニメーション。**AI生成可** |
| `イメージ` | 抽象カット。**AI生成可だが実在の場所を示唆しない**（`positioning.md` §4） |

**`現地撮影` が1行でもあるのに参拝記録が無い台本は、書いた時点で無効です。**

---

## 7. CTA

1本につき1つだけ。複数置くとどれも実行されません。

| 型 | 文言例 | 使いどころ |
| --- | --- | --- |
| `follow` | 「他の神社も回ってます」 | 発見系。シリーズ前提 |
| `profile` | 「詳しくはプロフィールから」 | リスト登録へ |
| `save` | 「参拝の前に見返してください」 | 作法・手順もの |
| `comment` | 「あなたの本命星、コメントで教えてください」 | 対話を作る。**返信できる本数のときだけ** |
| `watch_long` | 「詳しい由緒は長い方で話してます」 | 短尺→長尺 |
| `none` | — | 3本に1本はこれでよい |

`comment` 型は返信しないと逆効果です。返せる本数のときだけ使ってください。

---

## 8. 尺の検算

書き終えたら必ず：

```
音声の総文字数 ÷ 325字/分 ≒ 想定尺
```

これが枠を超えていたら、テンポを上げるのではなく**内容を削ります**。
早口は離脱を招きます。`schemas/validate.py` が自動検査します。

---

## 9. 語り口

- 敬体（です・ます）
- 主観には必ずマーカー：「私の見立てでは」「〜と感じています」
- 史実の不確かさにもマーカー：「〜と言われています」「諸説あります」
- 断定しない。**断定しないことが、この事業では強さになります**
- 引き受けない領域を言う（医療・法律・投資）ことも、そのまま信頼になる

**一人称での実務の語り**（「ご相談で多いのは」「対面を続けているのは」）は
事業ファクトです。Script Agent が創作してはいけません（`rules.md` §5.4）。
