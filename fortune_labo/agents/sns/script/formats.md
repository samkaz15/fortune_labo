# Script Agent — フォーマット仕様

対象4フォーマット。**同じ素材から複数の尺を作る**のが前提で、
尺ごとに別撮りはしません。

---

## 一覧

| フォーマット | 尺 | 画面比 | 話し言葉の文字数 | 主用途 |
| --- | --- | --- | --: | --- |
| **TikTok** | 15〜60秒 | 9:16 | 75〜300字 | 発見・拡散 |
| **Instagram Reels** | 15〜90秒 | 9:16 | 75〜450字 | 発見・世界観 |
| **YouTube Shorts** | 〜60秒 | 9:16 | 〜300字 | 発見・検索流入 |
| **YouTube 本編** | 5〜12分 | 16:9 | 1,500〜4,200字 | 深い理解・信頼 |

### 文字数の根拠

日本語のナレーションは **概ね 300〜350字/分**。落ち着いた語りなら 300字、
テンポを上げて 350字が上限です。それ以上は聞き取れません。

```
60秒 ≒ 300〜350字
30秒 ≒ 150〜175字
10分 ≒ 3,000〜3,500字
```

**台本を書いたら必ず文字数を数えてください。**60秒枠に450字入れるのが
最も多い失敗です。`schemas/validate.py` が自動で検査します。

## 構成テンプレート

### 短尺（TikTok / Reels / Shorts・15〜90秒）

```
0:00-0:03  フック      視覚・音声・テロップの3層（writing.md §2）
0:03-0:10  提示        何の話かを確定させる
0:10-0:40  本編        情報 → 理由
0:40-0:55  置き換え    現代の生活でどうするか
0:55-1:00  CTA         1つだけ
```

**0:03-0:10 を飛ばさないこと。**フックで引いた直後に「で、何の話？」が
解消されないと、ここで2回目の離脱が起きます。

### 長尺（YouTube 本編・5〜12分）

```
0:00-0:15   フック＋結論の予告
0:15-0:45   自己紹介と、この動画で分かること
0:45-2:00   背景（歴史・暦・由緒）
2:00-6:00   本編（章立て・各章2〜3分）
6:00-8:00   実践への落とし込み
8:00-9:00   まとめ
9:00-9:30   CTA
```

長尺は**章ごとに独立して成立**させます。途中から見た人が置いていかれない構成。

## 多尺展開

1つの参拝素材から作る順序：

```
① YouTube 本編（10分）を先に書く   ← 情報が最も多い。ここが原本
        ↓ 最も強い1点を抜く
② 短尺（60秒）                      ← 発見用
        ↓ さらに削る
③ 超短尺（30秒）                    ← 拡散用
```

**逆順にしないでください。**短尺から長尺を作ると、中身が薄いまま尺だけ伸びます。

ただし撮影は短尺を先に出しても構いません。**書く順序と出す順序は別**です。

## チャネル別の作法

### TikTok
- 冒頭の1秒で音が鳴っていること（無音スタートは離脱率が高い）
- テロップは画面中央〜やや上（下部はUIに隠れる）
- プラットフォーム提供の音源を使う（著作権。`rules.md` §4）

### Instagram Reels
- 世界観の一貫性が効く。単発より連作
- カバー画像の統一（プロフィールのグリッドが作品になる）

### YouTube Shorts
- タイトルに検索語を入れる（Shortsも検索に乗る）
- 長尺への導線を置く

### YouTube 本編
- 概要欄に出典を書く（`rules.md` §3 の事実確認と接続）
- チャプターを切る
- サムネイルは A11 Creative Agent の領域。**煽りサムネは禁止**（`rules.md` §2）

## 撮影の現実的制約

台本を書く前に確認すること。ここを飛ばすと撮れない台本ができます。

| 確認事項 | 未確認なら |
| --- | --- |
| その神社は撮影可か | 台本を書かない |
| 商用利用の許諾はあるか | 台本を書かない |
| 三脚・ジンバルは使えるか | 手持ち前提で書く |
| 他の参拝者が映り込むか | 引きの画を避ける構成にする |
| 音声は現地で録れるか | 後乗せナレーション前提で書く |

詳細は `rules.md` §4。
