# Prompt — 事実確認の受け渡し

## タスク
未検証のクレームを含む台本について `video_fact_check_request` を出す。

**自分で検証しません**（`rules.md` §3.6）。分類して、出典候補を挙げて、渡します。

## 動画固有の注意

### テロップは criticality を1段上げる

画面に焼き付いた情報は取り消しが効きません。音声なら「〜と言われています」で
ぼかせますが、テロップに「1200年の歴史」と出したら断定です。

`in_caption: true` のクレームは、`supporting` → `load_bearing` のように
1段上げて渡してください。

### 冒頭3秒のクレームは最も多く見られる

`in_hook: true` のクレームは、動画で最も多くの人が目にする情報です。
最後まで見る人は一部でも、冒頭は全員が見ます。

### 依頼は執筆より前に出す

動画は撮影コストが高く、事実が崩れると台本ごと捨てることになります。
テキストなら1文直せば済むところが、動画では撮り直しです。

## criticality

| 値 | 反証されたら |
| --- | --- |
| `load_bearing` | **台本ごと破棄。** 編集で逃げない |
| `supporting` | その一節を削る |
| `incidental` | 削るかぼかす |

## 出典候補

| 種別 | 例 |
| --- | --- |
| `shrine_official` | 神社公式の由緒・由緒書 |
| `government_or_municipal` | 自治体史・文化財説明 |
| `academic` | 学術論文・大学紀要 |
| `reference_work` | 国史大辞典・年中行事辞典 |
| `museum_or_archive` | 国立国会図書館デジタルコレクション |

**「検索して複数のサイトが同じことを書いている」は出典ではありません。**
まとめサイトは互いを写すので、創作された由緒はこうして広がります。

## 過度な一般化

「昔の日本人は全員○○していた」型は `overgeneralisation_risk: true` を立てます。
これは文体の問題ではなく事実の誤りです（`rules.md` §3.3）。
どの階層・地域・時代の習慣だったのかを検証者に尋ねてください。

## ぼかし案

検証が不確定に終わった場合の言い回しを先に用意します。
ぼかすと主旨が消えるなら、**そう書いてください**。その台本の生死が
そのクレームにかかっていることが検証者に伝わります。

## 緊急度

| 値 | 用途 |
| --- | --- |
| `standard` | 通常 |
| `seasonal_deadline` | 期日あり。`needed_by` は**撮影日から逆算**。編集・承認の日数を含める |
| `correction` | **公開済み動画が誤っている疑い。P0。** 即日人間へ |

## 返却後

| 判定 | 対応 |
| --- | --- |
| `verified` | 進む |
| `verified_with_hedge` | ぼかしを適用し `hedge_applied: true` |
| `unverifiable` | ぼかすか削る。断定しない |
| `refuted` + `load_bearing` | **台本を破棄。** 同じクレームが他の台本にないか確認 |

公開済みに `refuted` が出たら `correction` です。同日中に人間へ上げ、
非公開化と訂正動画を起案します。
