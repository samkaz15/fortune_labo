# Script Agent — KPI

## 設計方針

動画の既定の指標は再生数です。**この事業では最下位に置きます**
（`positioning.md` §1）。動画は発見のチャネルであって、発見の先に
リスト登録と鑑定予約が無ければ意味がありません。

`agents/sns/x/kpi.md` と同じ3層構造を使い、Strategy Agent が
チャネル間で比較できるようにします。

---

## KGI

> **動画経由のリスト登録数**、および**動画起点の鑑定予約数**。

---

| KPI | 定義 | Phase |

## Tier 2 — 発見と信頼（steer する層）

| KPI | 定義 | 目標方向 | なぜ |
| --- | --- | --- | --- |
| **`hook_retention_3s`** | 3秒時点の視聴維持率 | **↑ 最重要** | ここで決まる。台本の冒頭設計が直接効く唯一の指標 |
| **`avg_view_duration_rate`** | 平均視聴維持率 | ↑ | 本編が約束を果たしたか |
| **`profile_visit_rate`** | プロフィール遷移 ÷ 再生 | **↑** | 「誰が言ったか」に到達した瞬間 |
| **`save_rate`** | 保存 ÷ 再生 | ↑ | 後で見返す価値があったか |
| `share_rate` | シェア ÷ 再生 | ↑ | 人に言いたくなったか |
| `follow_rate` | フォロー ÷ 再生 | ↑ | 継続的な関心 |

制作工程の指標（Phase 1 から測れる）：

| KPI | 定義 | 目標 |
| --- | --- | --- |
| `basis_coverage` | basis を持つ台本 ÷ 全台本 | **= 1.0。下回ればルール違反であって数値未達ではない** |
| **`shoot_completion_rate`** | **撮影できた本数 ÷ 書いた本数** | **≥ 0.8** |
| `tier_a_ratio` | Tier V-A ÷ 公開本数 | ↑、下降させない |
| `ai_generated_ratio` | AI生成素材の秒数比 | **≤ 0.3** |
| `permission_clearance_rate` | 撮影許諾が事前に取れていた割合 | = 1.0 |
| `duration_accuracy` | 想定尺と実尺の乖離 | ±15% 以内 |
| `correction_count` | 公開後の訂正 | **= 0** |

### `shoot_completion_rate` が動画固有の要

書いた台本の8割が撮れていないなら、**台本が現実から離れています。**
許諾が取れない、素材が無い、尺が合わない。原因を特定せずに本数を増やしても
負債が積み上がるだけです（`positioning.md` §6）。

### `tier_a_ratio` は P0 アラート

再生数が伸びているのに Tier V-A の比率が落ちているなら、**一次情報から
離れて汎用コンテンツに寄っています。**`agents/seo/kpi.md` の
`firsthand_content_ratio` と同じ扱いで、トレードオフではなく失敗と判定します。

## Tier 3 — リーチ（診断のみ）

再生数、いいね、コメント数、フォロワー総数、インプレッション。

**単独で成果として報告しません。**Tier 1・2 の動きを説明するためだけに使います。

---

## 見るべき比率

```
profile_visit_rate ÷ save_rate
```

保存は多いのにプロフィール遷移が少ない動画は、**内容は良いが著者が見えていない**。
動画としては成功、事業としては失敗です。台本に本人が登場していないか、
名乗っていない可能性があります。

```
hook_retention_3s ÷ avg_view_duration_rate
```

3秒維持は高いのに平均維持率が低いなら、**フックが本編を上回っている**。
釣りに近づいています。`rules.md` §2 の回収されないフックの兆候です。

---

## 禁止する報告の仕方

- 「バズった」を成果として報告する
- 再生数の成長を Tier 1・2 と紐付けずに報告する
- フォロワー数の増加を単独の成果とする
- 台本の**本数**を成果とする（撮れた本数が成果）
- 1本の好成績をチャネルの成果として一般化する

レポートは必ず Tier 1 → 2 → 3 の順。

---

## 診断マトリクス

| 観測 | 原因の候補 | 担当 |
| --- | --- | --- |
| 3秒維持率が低い | フックの3層設計、特に視覚 | Script Agent |
| 3秒は高いが平均維持率が低い | フックが回収されていない | Script Agent |
| 維持率は高いがプロフィール遷移が低い | 本人が見えていない・名乗っていない | Script Agent |
| プロフィール遷移は高いがリスト登録が低い | プロフィール文・リンク導線 | A09 / A14 |
| リスト登録は増えるが予約が増えない | 動画の視聴者層がズレている | A01 Strategy |
| 再生数↑・`tier_a_ratio`↓ | **moat の毀損。P0** | Script Agent → A01 |
| `shoot_completion_rate` が低い | 台本が撮影の現実と乖離 | Script Agent（自らの失敗） |
| `duration_accuracy` が悪い | 文字数係数の調整不足 | Script Agent（自らの失敗） |
