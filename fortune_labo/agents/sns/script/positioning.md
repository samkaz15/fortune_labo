# Script Agent — Positioning

**Read this before any other file in `agents/sns/script/`.**
Every rule, format, and prompt in this directory exists to enforce what is
written here.

---

## 1. What video is for in fortune_labo

動画は**発見のチャネル**。保存でも購入でもなく、**まだこの占術師を知らない人に
最初に届く場所**です。

```
動画（発見）→ プロフィール → リスト登録 → 月次レポート（保存）→ 物販・鑑定（購入）
```

`agents/sns/x/positioning.md` §1 が X を「authority channel」と定義したのに対し、
動画は **discovery channel**。役割が違うので、指標も違います。

| | X | 動画 |
| --- | --- | --- |
| 役割 | 保存される／著者を調べられる | 発見される |
| 主要指標 | bookmark_rate | **視聴維持率・保存率・プロフィール遷移率** |
| 失敗の形 | 保存されない | **3秒で離脱される** |

---

## 2. 最初の3秒がすべて

動画の成否は 0〜3 秒で決まります。ここで離脱されたら、どれだけ中身が良くても
届きません。**台本の設計は、冒頭3秒から逆算して書きます。**

これは X のフックとは別物です。X は「読むかどうか」を決める1行ですが、動画は
**視覚・音声・テロップの3層が同時に**最初の3秒を作ります。

台本には常にこの3層を書きます（`writing.md` §2）。

---

## 3. 動画における moat

`agents/seo/positioning.md` §3 の moat は変わりません。

| 資産 | 動画でどう効くか |
| --- | --- |
| **一次体験（参拝）** | **動画が最も強いメディア。** 実際にそこに立っている映像は複製できない |
| **占術師の見解** | 顔と声が乗ると、文字より遥かに強く「誰が言ったか」が伝わる |

動画は moat と相性が最も良いチャネルです。テキストなら真似できても、
**実際に行った映像は、行った人にしか撮れません。**

裏返すと、素材が無ければこのエージェントは何も作れません。
現状 **参拝記録0件**。ここが最大の制約です。

## 4. AI生成映像の境界（重要）

SEEDANCE 等の動画生成AIは使えますが、**使える場所が限定されます。**

| 用途 | 可否 | 理由 |
| --- | --- | --- |
| 神社・参拝の情景を生成する | **禁止** | 一次体験の捏造。`agents/seo/rules.md` §2.1 |
| 実際の参拝映像の代替 | **禁止** | 同上 |
| 抽象的なイメージカット（光・水・季節感） | 条件付き可 | 実在の場所を示唆しないこと |
| 図解・アニメーション（暦の仕組み等） | 可 | 事実の可視化であって体験ではない |
| サムネイル背景 | 条件付き可 | 実在の神社に見えないこと |

条件付き可のものは **AI生成であることが分かる形にする**。
「本物に見えるAI生成映像」は、たとえ神社を映していなくても、この事業の
信頼を毀損します。検証可能性を差別化にしている以上、ここで嘘をつくと全部崩れます。

## 5. 動画のTier

`agents/sns/x/positioning.md` §5 の X-Tier に対応します。

| Tier | 定義 | 必要な素材 |
| --- | --- | --- |
| **V-A — Moat** | 実際の参拝映像／占術師本人が話す見解 | 撮影素材＋撮影許諾 |
| **V-B — Authority** | 暦・節句・日本文化の解説（出典あり） | 図解・資料映像・本人の語り |
| **V-C — Practice** | 開運アクションの解説・実演 | 本人の語り・実演映像 |
| **V-D — Forbidden** | 根拠のない運気断言／今日の運勢／星座ランキング／煽りサムネ | — |

V-D は禁止であって低優先ではありません（`rules.md` §1）。

---

## 6. 供給の制約

| Tier | 何に律速されるか |
| --- | --- |
| V-A | **参拝と撮影許諾**。AIでは増やせない |
| V-B | 事実確認のスループット |
| V-C | 占術師の収録時間 |

`x/positioning.md` §6 と同じ構造ですが、動画には**撮影という追加工程**があります。
台本だけ量産しても、撮れなければ本数は増えません。

**台本の本数ではなく、撮影できる本数で計画してください。**

---

## 7. Anti-goals

Script Agent は以下をしてはいけません。

1. 撮影許諾が未確認の神社を前提にした台本を書く
2. AI生成映像で一次体験を代替する台本を書く
3. 根拠のない運気断言（「これで運気が上がります」）
4. 恐怖訴求のフック（「知らないと損」「やらないと不幸になる」）
5. 回収されないフック（3秒で釣って本編で答えない）
6. 史実・由緒の創作
7. 撮影不可能な台本（存在しない画・許諾の取れない画を要求する）
8. 尺を無視した台本（60秒枠に90秒分の文字を入れる）
9. 同じ構成・同じフックの量産
10. 再生数のために basis を犠牲にする。衝突したら basis を優先し、エスカレーション

## 8. 一行テスト（継承・動画版）

台本を出す前に：

> **参拝もしていない、占術師もいないアカウントが、AIだけで同じ動画を
> 明日投稿できるか？**

できるなら作りません。

動画固有の追認：

> **音を消しても意味が伝わるか？**

多くの人は無音で見ます。テロップと画だけで成立しない台本は、
実際には半分しか届いていません。
