# Script Agent — Inputs

## 占術師本人から（代替不可）

| 入力 | なぜ本人しか出せないか |
| --- | --- |
| **参拝記録＋撮影素材** | `firsthand` の唯一の供給源。動画では実写そのもの |
| **撮影許諾のステータス（動画・商用）** | 法的関門。無ければ台本を書けない |
| 見解・占断とその根拠 | `practitioner_view` |
| 顔と声（本人収録） | 動画の信頼はここに乗る |
| 実際の相談質問 | 視聴者の言葉そのもの |
| 一人称の実務記述の確認 | 事業ファクト（`rules.md` §5.4） |
| **収録可能な時間** | 台本の本数を決める上限 |

最後が動画固有です。テキストと違い、**本人の収録時間が直接の律速**になります。

## A06 SEO Agent から

| 入力 | 用途 |
| --- | --- |
| 季節カレンダー（節句・二十四節気・祭事） | 撮影と公開の逆算 |
| 参拝計画（visit plan） | いつ `firsthand` 素材が増えるかの予告 |
| 検索需要 | YouTube のタイトル・検索流入 |

## A07 Content Strategy Agent から

承認済みテーマプール、編集カレンダー。

## A09 SNS Strategy Agent から

チャネル配分、投稿頻度、キャンペーン期間。

## A02 Research / A29 Fact-Check から

検証済みの史実・由緒・暦、出典。`verified_fact` の供給源。

## A11 Creative Agent から

ビジュアルの方向性、カラー、サムネイル。**Script Agent はこれを受け取る側**で、
指定する側ではありません（`mission.md` の境界表）。

## A10-X / 既存コンテンツから

X の投稿・記事・月次レポートはテーマ源です。**同じ素材を横展開**するのが
基本で、動画のためだけに新規取材はしません。

## フェーズ別の可用性

| Phase | 使えるもの | Script Agent の稼働 |
| --- | --- | --- |
| **1（現在）** | 本人の素材、季節暦、手動観測 | テーマ選定・台本執筆・ショットリスト。**完全に稼働可** |
| 2 | 動画分析API | フック型・Tier の実測による重み付け |
| 3 | 予約への寄与 | Tier 1 KPI |

**Phase 1 で完全に動きます。**API待ちの要素はありません。

## 現時点の入力ギャップ

| 不足 | 結果 |
| --- | --- |
| **参拝記録 0件** | **Tier V-A（実写）の台本は1本も書けない** |
| **撮影許諾フロー未整備** | 神社を映す台本はすべて保留 |
| 本人収録の環境・時間 | 未確定。台本の本数上限が決まらない |
| 事業ファクト（占術師名・サービス名・URL） | `{{placeholder}}` のまま |
| 標準免責文 | 未承認（`content/sns/README.md` §3 に案） |

最初の2つが解消されるまで、このエージェントが作れるのは
**本人収録＋図解のみで完結する台本（Tier V-B / V-C）**に限られます。
それでも着手はできます。
