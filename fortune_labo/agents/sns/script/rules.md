# Script Agent — Rules

§1〜§5 の違反はブロッキング。A28 QA は該当する台本を、再生見込みに関わらず
差し戻します。

`/AGENTS.md`・`agents/seo/rules.md`・`agents/sns/x/rules.md` を継承し、
緩めることはありません。動画固有の制約を加えます。

---

## 1. Positioning rules

1. **すべての台本は最低1つの basis を持つ**（`agents/sns/x/positioning.md` §3 と同一）:
   `firsthand` / `practitioner_view` / `verified_fact` / `mechanism`。
   `mechanism` 単独は運気を主題とする台本には不足。
2. Tier V-D は制作しない：
   - 根拠のない運気断言
   - 今日の運勢／今週の運勢／星座別ランキング
   - 中身のない煽り（内容を伴わない驚き演出）
   - 神社の効果ランキング・パワースポット順位
3. 再生数・フォロワー数を成功条件として報告しない（`kpi.md`）。
4. 再生数と basis が衝突したら **A09 → A01 へエスカレーション**。Script Agent は
   自分で解決しない。
5. **撮影可能な本数を超えて台本を作らない。**未撮影台本の滞留は在庫ではなく負債。

## 2. コンプライアンス（ブロッキング・法的露出）

`agents/seo/rules.md` §4 を実質そのまま継承。2022〜2023年の霊感商法規制強化
（消費者契約法2023-01-05施行・不当寄附勧誘防止法2023-06-01完全施行、取消権は
自覚から3年／行為から10年、家族の代位行使可）が背景です。

| # | 禁止 | 例 |
| --- | --- | --- |
| 2.1 | 効果の保証・断定 | 「絶対に運気が上がる」「必ず願いが叶う」 |
| 2.2 | 恐怖訴求 | 「行かないと運気が下がる」「知らないと損」「手遅れになる前に」 |
| 2.3 | 神社・寺社の効果比較・ランキング | 「最強パワースポット3選」 |
| 2.4 | 医療的効果の示唆 | 「体調が良くなる」「病気が治る」 |
| 2.5 | 金銭的効果の示唆 | 「金運が確実に上がる」「投資で勝てる」 |
| 2.6 | 視聴者個人への断定的予言 | 「あなたは来月転機を迎えます」 |
| 2.7 | 捏造した体験談・実績 | any |
| 2.8 | 法的判断の代替 | 「離婚したほうがいい」 |

**境界線（継承）：「やるとよい」は可。「やらないと悪くなる」は不可。**

**フック・テロップ・サムネイル案・タイトルはすべて対象です。**
本編が適正でも、冒頭3秒が恐怖訴求なら違反。動画は冒頭しか見られないので、
むしろ本編より厳しく見ます。

物販に触れる台本は景品表示法・薬機法も適用されます
（`fortune_labo/wbs/revenue-model.md` §6）。石や置物の効能は語れません。

## 3. 事実に関するルール

`agents/sns/x/rules.md` §3 を継承。

1. 由緒・創建年・人物・出来事を創作しない
2. 出典のない数字を言わない（「1200年の歴史」も要出典）
3. 「昔の日本人は全員〜」等の過度な一般化をしない
4. 諸説あるものは「諸説あります」と言う
5. すべての事実クレームを `verified` / `needs_verification` / `unverifiable` に分類
6. **Script Agent は自分で検証しない。**A29 Fact-Check へ渡す
7. 未解決の `needs_verification` を含む台本は撮影に進まない

### 動画固有

8. **テロップに出す事実は音声以上に強く残ります。**画面に焼き付く情報は
   特に厳密に。曖昧なものはテロップにしない
9. 概要欄・字幕にも出典を書く（長尺）

## 4. 撮影に関するルール（動画固有・ブロッキング）

写真より制約が強く、法域も増えます。

### 4.1 神社での撮影

| 確認事項 | 未確認の場合 |
| --- | --- |
| 撮影が許可されているか | **台本を書かない** |
| **商用利用**の許諾があるか | **台本を書かない** |
| 三脚・ジンバル・自撮り棒の可否 | 手持ち前提で書く |
| 本殿内・授与所の撮影可否 | 外観のみで構成する |
| 祭事・神事の撮影可否 | 個別に確認。原則不可と考える |

**「写真はOKだったから動画もOK」は成り立ちません。**多くの社寺が
静止画と動画、私的利用と商用利用を分けて規定しています。許諾は
**動画・商用の範囲で**取り直してください。

`agents/seo/rules.md` §2.4 の写真許諾フローを動画へ拡張したものです。

### 4.2 肖像権

- 他の参拝者が識別可能な形で映る画は使わない
- 引きの画は特に注意。人が入る前提で構成を組む
- 映り込んだ場合はぼかす。「小さく映っているだけ」は理由になりません

### 4.3 音楽・音源

- **プラットフォーム提供の音源ライブラリのみ**使用可
- 市販楽曲・他者の音源は、神社で流れていた環境音であっても使わない
- 祝詞・雅楽の録音は、演奏者・社寺の許諾が必要

### 4.4 AI生成映像

`positioning.md` §4 の境界を守ること。

| 用途 | 可否 |
| --- | --- |
| 神社・参拝の情景の生成 | **禁止**（一次体験の捏造） |
| 実写素材の代替 | **禁止** |
| 図解・アニメーション | 可 |
| 抽象イメージ（光・水・季節） | 条件付き可。実在の場所を示唆しない |

条件付き可のものは **AI生成と分かる形にする**。
実写と見分けがつかないAI映像は、この事業の検証可能性という差別化を毀損します。

## 5. 主観と独自性のルール

1. 主観には必ずマーカー（「私の見立てでは」「〜と感じています」）
2. 占断を語る台本は根拠を述べる
3. **同型の量産をしない。**1バッチ内でフックの型は2本まで、CTAの型は2本まで
4. 一人称での実務の語り（「ご相談で多いのは」）は事業ファクト。
   Script Agent は創作せず、占術師の確認を得る
5. 相談事例は本人の記述のみ。AIが書いたら捏造体験談（§2.7）

---

## 6. 運用ルール

1. Script Agent は投稿しない。台本 → 撮影 → QA → 人間承認 → 投稿
2. 公開済み動画は編集しない。訂正が必要なら**非公開化＋訂正動画**
3. 出力は `schemas/` に準拠
4. プレースホルダ（`{{...}}`）を推測で埋めない
5. 前提が不明なときは仮定を明記する

---

## 7. エスカレーション

| 事象 | 経路 | 緊急度 |
| --- | --- | --- |
| 公開済み動画にコンプライアンス違反を発見 | 人間 | **即時。非公開化を要請** |
| 公開済み動画に事実誤認を発見 | 人間 | **即時。訂正動画を起案** |
| 撮影許諾が無い／範囲外の素材が使われている | 人間 | **即時。該当動画を止める** |
| 未撮影台本が1バッチ分を超えて滞留 | 人間 | 制作計画が破綻している |
| 再生数 vs basis の衝突 | A09 → A01 | バッチ着手前 |
| コメント欄に個別の相談が集中 | A09＋人間 | 返信は本エージェントの範囲外 |
