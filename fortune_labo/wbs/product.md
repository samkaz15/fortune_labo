# プロダクト定義

`revenue-model.md` の4チャネルを支えるプロダクト群。
**P0では何も作りません。** 全て手動で回して需要を確認してから作ります。

---

## 全体像

```
              ┌──────────────────────────────────┐
              │  P1  月次九星気学レポート            │  ← ハブ。全チャネルの上流
              │  無料版 / 有料版980円              │
              └──────────────┬───────────────────┘
                             │ 本命星・生年月日・相談履歴
          ┌──────────┬───────┴────────┬──────────────┐
          ▼          ▼                ▼              ▼
      ┌───────┐  ┌────────┐     ┌─────────┐   ┌──────────┐
      │ P2 EC │  │P3 鑑定  │     │P4 占い師 │   │P5 法人   │
      │ 物販  │  │ 予約   │     │ 管理    │   │ 講座     │
      └───────┘  └────────┘     └─────────┘   └──────────┘
```

P1が持つ**本命星という属性**が、P2〜P5すべての精度を決めます。
ここを先に作る理由です。

---

## P1 — 月次九星気学レポート（最優先）

### 何を届けるか

| 版 | 内容 | 価格 |
| --- | --- | --- |
| 無料 | 本命星別の今月の傾向 | 0円 |
| 有料 | 今月の詳細＋**翌月のネクストアクション**＋個別質問1回/月 | 980円/月 |

### 生成の仕組み

```
入力: 生年月日
  ↓ 機械計算（決定的・検証可能）
本命星（9種）／ 月命星 ／ 今月の月盤 ／ 翌月の月盤
  ↓ テンプレート選択
108テンプレート（9星 × 12ヶ月）= 占術師本人が執筆
  ↓ パーソナライズ層
相談履歴・過去の購入・登録時アンケート
  ↓
配信（LINE / メール）
```

**計算は機械、見立ては人間。** この境界を崩さないことが `positioning.md` §3 の
moat を守る条件です。AIに見立てを書かせた瞬間、汎用AI占いと区別がつかなくなります。

### 108テンプレート

```
9星 × 12ヶ月 = 108本
```

この事業で**唯一かつ最大の一回限りの投資**です。一度書けば以降の配信は自動化でき、
翌年は改訂のみ。WBS 1.1 で3ヶ月かけて分割執筆します（月36本 = 週9本）。

各テンプレートに必ず含めるもの：

| 要素 | 理由 |
| --- | --- |
| 今月の傾向 | 無料版の中身 |
| **翌月のネクストアクション（3つ以内）** | 継続率の源泉。来月戻る理由 |
| 占断の根拠 | `agents/seo/rules.md` §3.2。検証可能性が差別化 |
| 主観マーカー（私の見立てでは） | 同 §3.1 |
| 物販への自然な接続点 | 「整えるなら」の文脈。押し売りにしない |
| 標準免責文 | 同 §3.4 |

### 手動フェーズ（P0、明日から）

**プロダクトを作る前に、スプレッドシートとLINE公式で手動配信します。**

- 9星ぶんの10月レポートを手書き → LINEで一斉配信
- 有料版はまず個別課金（振込・PayPay等）でも可
- 100人集まる前に自動化しない

需要が確認できてから作る。これが P1 を P2 より先に、しかし
**自動化は P1 より後に**置いている理由です。

## P2 — 物販EC

### 差別化の構造

一般的なECのレコメンド：行動履歴（何を見たか・買ったか）から推定
このECのレコメンド：**登録時点で本命星が確定している**

```
登録 → 生年月日 → 本命星 → セグメント確定 → 初回から精度の高い提案
```

コールドスタート問題が構造的に存在しません。

### 商品構成（想定）

| カテゴリ | 客単価 | 粗利率 | 備考 |
| --- | --: | --: | --- |
| 天然石・パワーストーン | 3,000〜15,000円 | 55〜70% | 本命星別の提案がしやすい |
| 置物・オブジェ | 8,000〜50,000円 | 50〜60% | 客単価が高い |
| インテリア（方位関連） | 5,000〜30,000円 | 45〜55% | 九星気学と接続しやすい |
| 御守り・季節品 | 1,500〜5,000円 | 60〜70% | 初回購入のハードルが低い |

**目標客単価9,000円**は、初回は低単価、リピートで高単価という想定です。

### 表現の制約（最重要）

商品ページは `revenue-model.md` §6 の法域に入ります。

| 書けない | 書ける |
| --- | --- |
| 金運が上がります | 金運を意識する方に、昔から用いられてきました |
| 開運確実 | — （代替表現なし。使わない） |
| 体調が良くなります | — （健康への言及は全面禁止） |
| これがないと運気が下がります | — （恐怖訴求。消費者契約法の取消権リスク） |

**商品を仕入れる前に表現ルールを確定させること。**
売れない表現しかできない在庫を抱えるのが最悪です。

## P3 — 鑑定予約

| 機能 | 内容 |
| --- | --- |
| 予約 | 対面・オンラインの枠管理 |
| 事前情報 | 生年月日・本命星・相談内容は登録済み |
| 決済 | 自社決済（ココナラ経由22%の手数料を回避） |
| 鑑定後 | レポート送付＋物販レコメンド |

月2,000件を1人ではこなせません。**占い師20名体制**が前提で、
それが P4 の理由です。

---

## P4 — 占い師管理

自社以外の占い師を乗せる基盤。誰を乗せるかがブランドを決めるため、
**審査基準を先に作ってから**募集します。

| 機能 | 内容 |
| --- | --- |
| 審査 | 実績・手法・コンプライアンス理解 |
| 案件配分 | 相談内容と占術の相性でマッチング |
| 品質管理 | 鑑定後の評価、禁止表現の監査 |
| 精算 | テイクレート方式 |

---

## P5 — 法人・講座

単価が桁違いで、少数顧客で売上が立ちます。
プロダクトというより営業とコンテンツの組み合わせです。

| 商品 | 単価 |
| --- | --- |
| 法人顧問（経営判断の時期相談） | 年100〜200万円 |
| 社内研修・講演 | 30〜80万円/回 |
| 一般向け講座（九星気学入門） | 3〜10万円/人 |

## 開発順序と理由

| 順 | 何を | いつ | なぜこの順番か |
| --: | --- | --- | --- |
| 0 | **何も作らない**（手動運用） | P0 | 需要の確認が先。作ってから売れないのが最悪 |
| 1 | 108テンプレート | P1 | プロダクトではなく資産。これがないと自動化する中身がない |
| 2 | レポート自動配信 | P2前半 | 手動が限界（1,000人）を超えてから |
| 3 | EC | P2後半 | 粗利の主力。広告を回す原資になる |
| 4 | 鑑定予約 | P3 | 既存収益の効率化。急がない |
| 5 | 占い師管理 | P3後半 | 鑑定を2,000件/月にするために必要 |
| 6 | 法人 | P4 | 実績ができてから |

**EC を鑑定予約より先に置いています。** 鑑定予約は既存売上の効率化ですが、
EC は新しい粗利を生み、それが広告費の原資になるためです。
広告が回り始めるかどうかが、24ヶ月で12億に届くかの分岐点です。
