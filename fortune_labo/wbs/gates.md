# ゲートと撤退基準

WBS には6つのゲートがあります。各ゲートは**その時点で12億円到達が
まだ数学的に可能かどうか**を判定します。

目的は目標を守ることではなく、**到達不能が確定した時点で早く気づくこと**です。

---

## ゲート一覧

| ゲート | 判定日 | 経過 | 通過条件 | WBS |
| --- | --- | --: | --- | --- |
| **G0** | 2026-10-12 | 1ヶ月 | レポート27本 / リード100人 / 課金者1人以上 / 物販売上1件以上 | 0.G |
| **G1** | 2026-12-12 | 3ヶ月 | 108本完成 / リード1,000人 / 課金100人 / 物販粗利率55%実証 | 1.G |
| **G2** | 2027-03-12 | 6ヶ月 | 自動配信稼働 / EC稼働 / リード5,000人 / 月商300万円 / LTV/CAC≧3 | 2.G |
| **G3** | 2027-09-12 | 12ヶ月 | 月商2,000万円 / リード50,000人 / 占い師20名 | 3.G |
| **G4** | 2028-03-12 | 18ヶ月 | 月商5,000万円 / リード100,000人 / LTV/CAC≧3 | 4.G |
| **G5** | 2028-09-12 | 24ヶ月 | 月商1億円（年商12億円ランレート） | 5.G |

## G0（1ヶ月）— 一周回ったか

**売上の大きさは問いません。** 問うのは、配信 → 反応 → 課金 → 物販という
一周が実際に回るかどうかです。

課金者1人・物販1件という基準は意図的に低く設定しています。
「払う人が存在する」ことの最初の証拠さえあればよく、
**この段階で数を追うとプロダクト化の判断を誤ります**。

| 判定 | 対応 |
| --- | --- |
| 通過 | P1（108本執筆）へ |
| レポート本数のみ未達 | 執筆速度が律速。P1のスケジュールを1ヶ月延ばす |
| 課金者ゼロ | **価格ではなく提供内容を疑う。** 翌月ネクストアクションが弱い可能性 |
| リードが30人未満 | 告知手段の問題。既存顧客への個別連絡が機能していない |

## G1（3ヶ月）— 需要があるか

108本の完成が最大の条件です。**これがないと自動化する中身が存在しません。**

物販の粗利率55%の実証も同じ重みです。ここが45%だと
`revenue-model.md` の許容CAC 8,250円が崩れ、広告が回らなくなります。
**広告が回らないと24ヶ月では届きません。**

| 判定 | 対応 |
| --- | --- |
| 全項目通過 | P2（プロダクト化）へ |
| 108本が80本以下 | **P2に進まない。** 執筆を完了させる。作ってから中身がないのが最悪 |
| 粗利率が50%未満 | 仕入れ先の再選定、またはオリジナル商品開発の前倒し |
| リード1,000人未達 | 獲得手段を見直す。この時点で詰まると以降すべてが連動して遅れる |

## G2（6ヶ月）— 自動化とECが動くか

ここで初めて**LTV/CACの実測値**が出ます。この事業で最も重要な数字です。

| 判定 | 対応 |
| --- | --- |
| 全項目通過 | P3へ。有料広告を本格投下してよい |
| **LTV/CAC < 3** | **広告を止め、オーガニック専業に戻す。** 到達期間を30〜36ヶ月へ延長 |
| EC未稼働 | 物販が主力のため致命的。他を止めてでもECを優先 |
| 月商300万円未達 | 単価か転換率のどちらが原因かを分離してから対処 |

LTV/CAC が3を切った状態で広告を増やすのは、**赤字を加速させる行為**です。
「規模が出れば改善する」という仮定は、この事業では成立しません。

## G3（12ヶ月）— 4チャネルが揃ったか（最重要ゲート）

**12億円の成否は実質ここで決まります。** 24ヶ月目の月商1億円に対し、
12ヶ月目に2,000万円（1/5）が必要です。指数成長を前提にした最低ラインで、
余裕のある数字ではありません。

占い師20名も同じ重みです。鑑定2,000件/月は1人では不可能で、
**供給側が作れなければ鑑定チャネルは永久に月200万円で頭打ち**になります。

| 判定 | 対応 |
| --- | --- |
| 全項目通過 | P4へ |
| 月商1,000万円未満（半分以下） | **2年12億は不可能と確定。** 目標を再設定する（下記） |
| 占い師が10名未満 | 鑑定チャネルを諦め、物販とサブスクに構成比を寄せて再計算 |
| リードが25,000人未満 | 獲得が律速。広告効率か、コンテンツの質か、どちらかを特定 |

## G4（18ヶ月）— 資本を入れて伸びたか

| 判定 | 対応 |
| --- | --- |
| 全項目通過 | P5へ |
| 月商3,000万円未満 | 24ヶ月での到達は不可能。**30〜36ヶ月へ延長** |
| LTV/CAC が悪化 | 広告を絞り、リピート率の改善に資源を移す |
| 在庫回転が悪化 | **最優先で対処。** 物販の成長は黒字倒産を招きやすい |

## G5（24ヶ月）— 到達したか

| 判定 | 対応 |
| --- | --- |
| 月商1億円以上 | 目標達成。次の2年計画へ |
| 未達 | **未達幅と要因を記録し、翌年計画へ引き継ぐ。** 失敗として処理しない |

## 目標の再設定について

G2〜G4 で未達が確定した場合、取りうる選択肢は3つです。
**どれも失敗ではありません。**

| 選択肢 | 内容 | 向いている状況 |
| --- | --- | --- |
| **期間を伸ばす** | 12億円の到達を30〜42ヶ月に | 単位あたりの経済性は成立、伸び方が遅いだけ |
| **金額を下げる** | 2年で3〜5億円に | 構造は良いが獲得速度が想定より遅い |
| **構成比を変える** | 物販とサブスクに寄せ、鑑定とマッチングを縮小 | 占い師の供給が作れなかった場合 |

3番目は `positioning.md` が元々推奨していた「占術師本人が product」という
方向に近づきます。そこに戻ることは後退ではなく、**証拠に従って仮説を
更新した結果**です（`/AGENTS.md` の決定階層）。

## 早期警戒指標（ゲートを待たずに見るもの）

ゲートは3〜6ヶ月おきですが、以下は**毎週**見てください。
どれかが崩れると、次のゲートは必ず落ちます。

| 指標 | 週次の目安 | 崩れたときの意味 |
| --- | --- | --- |
| **新規リード獲得数** | P3以降は週1,600人 | 全チャネルの上流。ここが止まると4つ同時に止まる |
| レポート開封率 | 40%以上 | 下がるとサブスクも物販も連動して落ちる |
| 翌月ネクストアクションへの反応 | 返信・質問が出ているか | 無反応なら継続率が先に崩れる |
| 物販の粗利率 | 55%以上 | 割引販売に逃げていないか |
| 在庫回転日数 | 90日以内 | 運転資金の健全性 |

## ゲート判定の運用

- 判定は**人間のみ**が行います（自動化レベル C）。AIは数値を用意するだけです
- 判定結果は通過・未達にかかわらず**必ず記録**します
- 未達を「もう少しで届く」として通過させないこと。それがゲートを置く意味を失わせます
- 判定日はWBS上の固定日です。前倒し・先送りしません
