# 収益モデル — 2年で年商12億円

起算 2026-09-13 → 2028-09-12（24ヶ月）。
目標は **24ヶ月目に月商1億円（年商12億円ランレート）**。

WBS の全タスクはこの分解から導かれます。**数字が変われば WBS も変わります。**

---

## 1. 前回モデルからの変更点

物販が入ったことで、事業の成立確率が上がりました。理由を先に書きます。

| | 旧モデル（サブスク中心） | **新モデル（物販中心）** |
| --- | --- | --- |
| 主力チャネル | アプリ課金 980円/月 | **物販EC 客単価9,000円** |
| 必要ユーザー規模 | MAU 100万人 | **アクティブリスト 17万人** |
| 粗利LTV | 7,840円 | **24,750円** |
| 許容CAC（LTV/CAC=3） | 2,613円 | **8,250円** |
| 有料広告 | **回らない**（CAC 5,000〜15,000円に届かない） | **回る** |

**これが決定的な差です。** ARPU 980円のサブスク単体では、広告で顧客を買うと
赤字になるため、オーガニック獲得だけが選択肢でした。物販の粗利が乗ることで
広告が成立し、獲得速度を資本で買えるようになります。

必要ユーザー数も 100万MAU → 17万リストへ。前者は国内占いアプリ上位3位圏の規模、
後者はコンテンツと広告で24ヶ月あれば届くレンジです。

## 2. 12億円の分解（月商1億円）

| チャネル | 月商 | 粗利率 | 月次粗利 | 前提 |
| --- | --: | --: | --: | --- |
| **物販EC**（石・置物・インテリア） | 4,500万円 | 55% | 2,475万円 | 客単価9,000円 × 5,000件/月 |
| **個人鑑定**（自社＋所属占い師） | 2,000万円 | 60% | 1,200万円 | 単価10,000円 × 2,000件/月 |
| **サブスク**（月次鑑定レポート有料版） | 2,000万円 | 90% | 1,800万円 | 会員20,000人 × 980円 |
| **法人・講座・イベント** | 1,000万円 | 70% | 700万円 | 年契約・登壇・講座 |
| **その他**（アフィリエイト・広告） | 500万円 | 80% | 400万円 | |
| **合計** | **1億円** | **66%** | **6,575万円** | |

年商12億円 / 年間粗利 約7.9億円。ここから人件費・広告費・物流費を引いたものが営業利益です。

### なぜこの構成比か

物販が最大なのは、**占いと物販の接続がこの事業の最も強い差別化点**だからです。

```
生年月日 → 本命星が確定 → セグメントが自動で決まる → 商品レコメンドの精度が上がる
```

Amazon も Google 広告も「この人の本命星は三碧木星」という属性を持っていません。
一般的なECのレコメンドが行動履歴に基づくのに対し、こちらは**購入前から属性が確定**
しています。リストに登録された瞬間から、何を薦めるべきかが決まる構造です。

## 3. リストの逆算（事業の中心指標）

| 指標 | 必要値 | 根拠 |
| --- | --: | --- |
| **アクティブリスト** | **170,000人** | 事業の中心指標 |
| 物販の月次購入率 | 3% | 170,000 × 3% = 5,100件/月 |
| サブスク転換率 | 12% | 170,000 × 12% = 20,400人 |
| 月あたり必要獲得数 | 約7,000人 | 24ヶ月で170,000人 |

**月7,000リスト**が全ての土台です。これを下回ると全チャネルが連動して未達になります。

獲得の内訳（想定）：

| 経路 | 月あたり | 単価 |
| --- | --: | --- |
| オーガニック（SNS・SEO・動画） | 4,000人 | 実質0円（時間コスト） |
| 有料広告（LINE友だち追加・Meta） | 3,000人 | CPL 800〜1,500円 |

有料広告に月300〜450万円。許容CAC 8,250円に対し、リード→購入転換20%なら
CPL 1,650円まで払えるため、成立します。

## 4. リードマグネットの設計

獲得の入口は**「今月の九星気学レポート＋翌月のネクストアクション」**。

| | 内容 | 価格 |
| --- | --- | --- |
| **無料版** | 本命星別の今月の傾向（9種） | 0円 |
| **有料版** | 今月の詳細＋**翌月のネクストアクション**＋個別質問1回 | 980円/月 |

### なぜ「翌月のネクストアクション」が効くか

今月の運勢だけなら、生成AIが無料で無限に出します（`positioning.md` §2 の指摘通り）。
**翌月の行動指示**は違います。

1. 読者が**来月も戻ってくる理由**になる（継続率）
2. 「何をすればいいか」が書いてあるので**物販への自然な接続点**になる
3. 当たり外れが翌月に判定されるため、**占術師の実力が可視化される**

3つ目は諸刃ですが、`rules.md` §3.3 の「翌年の公開レビュー義務」と同じ思想です。
検証可能にすることが、検証不能な占いとの差になります。

### 108テンプレート — プロダクト化の鍵

```
9星（本命星） × 12ヶ月 = 108パターン
```

これを占術師本人が一度作れば、**以降の配信は自動化できます**。
月盤の計算は機械、見立ては本人。翌年は改訂のみ。

**108本の執筆が、この事業のプロダクト化における最大の一回限りの投資です。**
WBS ではこれを P1 の中心タスクに置いています（分割して3ヶ月で完了）。

## 6. 物販に固有のリスク（法域が変わります）

コンテンツの表現規制（既存 `agents/seo/rules.md` §4）とは**別の法律**が適用されます。

| 法律 | 何が問題になるか | 対応 |
| --- | --- | --- |
| **景品表示法** | 「金運が上がる」「開運確実」は優良誤認表示。措置命令・課徴金の対象 | 商品説明は「〜と言われています」「伝統的に〜とされてきました」に限定 |
| **薬機法** | 「病気が治る」「体調が良くなる」は医薬品的効能効果の標榜 | 健康への言及を全面禁止 |
| **特定商取引法** | 通信販売の表示義務、返品特約 | 特商法表記・返品規定を先に整備 |
| **消費者契約法（2023年改正）** | 霊感等による知見を用いた告知での取消権（3年/10年） | 「この石を買わないと不幸になる」型の販売は絶対不可 |

**「開運グッズ」という商品カテゴリ名自体は一般に使われていますが、
効果を保証する表現は使えません。** ここは商品ページ1枚単位で管理が必要です。

WBS 0.4 と 2.4 に必須タスクとして入れてあります。
**商品を仕入れる前に表現ルールを確定させてください。** 順序が逆になると、
仕入れた在庫が売れない表現しかできない、という事態になります。

## 7. 既存チャットログの利用について（要注意）

「今まで行ってきたチャット」をリードマグネットに入れる件、これは
**個人情報保護法の対象**です。占いの相談内容は機微性が高く、本人が読めば
特定できる粒度で転用すると問題になります。

| やり方 | 可否 |
| --- | --- |
| 相談内容をそのまま掲載 | **不可**（同意があっても推奨しない） |
| 個人が特定できない形に加工して掲載 | 条件付き可（同意＋加工の妥当性確認） |
| **質問の「型」を抽出して、回答の設計に使う** | **推奨。これが本来の使い方** |

3番目が正しい活用です。100件の相談から「決断の時期に関する質問が4割」という
構造を抽出し、**レポートの構成そのものをそれに合わせる**。個別ケースを載せる
必要はありません。

顧客の実際の言葉は `agents/seo/inputs.md` が「システム内で最も価値の高い
キーワード源」と位置づけているものです。価値はケースの中身ではなく、
**何を聞かれるかの分布**にあります。

WBS 0.5 に、同意確認と匿名化の手順を入れてあります。

| 資本 | 未調達。広告費だけで月300〜450万円 | 1.6 / 3.5 |
| 組織 | 実質1名。24ヶ月目には15〜20名規模 | 3.6 / 4.5 |
| 占い師の供給 | 本人1名。2,000件/月には20名規模が必要 | 3.2 |

前回モデルより成立確率は上がりましたが、**依然として資本と組織が律速**です。
だからこそ [`gates.md`](./gates.md) に5つの判定点を置いています。

到達しないことより、**到達しないと分かる時期が遅れること**のほうが損失が大きい、
という設計は変わりません。
