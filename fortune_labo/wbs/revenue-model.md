# 収益モデル — 2年で年商10億円

WBS の全タスクはこの分解から導かれています。
数字が変われば WBS も変わります。**先にここを合意してください。**

---

## 1. 目標の定義（要確定 / WBS 0.2.1）

「2年で10億円」には2つの読み方があり、必要な最終月商が変わります。

| 解釈 | 意味 | 24ヶ月目に必要な月商 |
| --- | --- | --- |
| **A. 累計** | 24ヶ月の売上合計が10億円 | **1.5〜2.0億円** |
| **B. ランレート（本WBSの採用案）** | 24ヶ月目の年換算売上が10億円 | **8,333万円** |

指数的に伸びる事業では、累計10億のほうが最終月商は高くなります（立ち上がりの
数ヶ月がほぼゼロのため、後半で取り戻す必要がある）。

**本WBSは B を採用**しています。A を選ぶ場合、P3・P4 の数値目標を約2倍に
引き上げる必要があります。

---

## 2. 現行モデルでは到達しない（確認された事実）

参照シートの現状値：

| 項目 | 値 |
| --- | --- |
| 現在のKPI | 月商150万円 |
| 鑑定単価 | 10,000円 |
| 決済手数料 | 7%（ココナラ経由は22%） |
| ツール利用料 | 10,000円/月 |

対面鑑定のみで10億円を作る場合：

```
10億円 ÷ 10,000円 = 100,000件
100,000件 ÷ 730日  = 137件/日
```

1人の占術師では不可能です。仮に1日8件・月200件（かなりの高稼働）としても：

```
200件 × 10,000円 × 12ヶ月 = 年商 2,400万円
```

**目標の 2.4%。** 対面鑑定は10億円の器ではありません。
これは伸ばし方の問題ではなく、構造の問題です。

## 3. 10億円ランレートの分解（月商8,333万円）

| 収益源 | 月商 | 前提 | 検証する場所 |
| --- | --: | --- | --- |
| **アプリ課金（サブスク）** | 4,000万円 | 課金会員 41,000人 × ARPU 980円 | WBS 2.1 / 2.2 |
| **占い師マッチング手数料** | 2,500万円 | GMV 8,300万円 × テイクレート30% | WBS 2.3 / 3.2 |
| **法人向け（ビジネス占い）** | 1,000万円 | 年契約120万円 × 100社 ÷ 12 | WBS 3.3 |
| **自社鑑定（対面・オンライン）** | 500万円 | 単価10,000円 × 500件（複数鑑定士） | WBS 4.1.4 |
| **その他（広告・物販）** | 333万円 | | WBS 4.1.5 |
| **合計** | **8,333万円** | | |

構成比の意味：**アプリ単体では届きません。** サブスクだけで10億を作るには
課金会員が85,000人必要で、これは国内占いアプリのトップクラスに相当します。
マッチングと法人の3本柱にすることで、各項目の難易度を現実的な水準に下げています。

## 4. アプリ課金の逆算

課金会員 41,000人を得るために必要なユーザー数：

| 無料→課金の転換率 | 必要MAU |
| --: | --: |
| 3% | 1,367,000 |
| **4%（想定）** | **1,025,000** |
| 6% | 683,000 |
| 10% | 410,000 |

**MAU 100万人は、国内の占いアプリカテゴリで上位3位圏の規模です。**
これを24ヶ月でゼロから作る前提であることを、明示的に認識してください。

### ARPU の感応度

| ARPU | 必要な課金会員数 | 必要MAU（転換率4%） |
| --: | --: | --: |
| 480円 | 83,000 | 2,080,000 |
| **980円** | **41,000** | **1,025,000** |
| 1,980円 | 20,200 | 505,000 |
| 2,980円 | 13,400 | 335,000 |

**ARPU を上げるほど必要ユーザー数は劇的に下がります。**
980円の汎用プランではなく、占術師の個別性を含む上位プラン（1,980〜2,980円）を
主力に置く設計のほうが、到達確率は高くなります。WBS 2.2.3 で見直します。

## 5. CAC の制約（この事業の最重要論点）

```
LTV = ARPU 980円 × 平均継続 8ヶ月 = 7,840円
健全な上限CAC（LTV/CAC = 3）      = 2,613円
```

国内の課金アプリで、有料広告経由の課金ユーザー1人あたり獲得コストは
一般に5,000〜15,000円です。**つまり ARPU 980円では、有料広告だけで
ユーザーを買うと赤字になります。**

結論は2つのいずれかです。

1. **ARPU を上げる**（1,980〜2,980円）→ 上限CACが 5,300〜8,000円になり広告が成立する
2. **オーガニック獲得を主軸にする** → SEO・SNS・動画。CACはほぼゼロだが時間がかかる

参照シートのベンチマーク値がこれを裏づけています：

| 平均CTR | 平均CVR | 獲得効率 | 必要インプレッション |
| --: | --: | --: | --: |
| 1.80% | 2.50% | 0.045% | 74万 |
| 1.00% | 2.20% | 0.022% | 152万 |
| 1.50% | 0.80% | 0.012% | 278万 |

**この制約こそが、既に構築済みの SEO Agent / X Content Agent への投資を
正当化しています。** コンテンツエンジンは補助線ではなく、この単価では
唯一成立する獲得チャネルです。

## 6. `positioning.md` との矛盾（エスカレーション事項 / WBS 0.2.4）

リポジトリの `agents/seo/positioning.md` §2 はこう記録しています。

> 矢野経済研究所（2023年度）が国内占いサービス市場を約997億円と推計。
> 6セグメント中5つが成長、**唯一横ばいだったのが「Web占い（アプリ/SNS）」
> ——人が介在しないセグメント**。生成AIはこの領域を完全にコモディティ化した。

**10億円の目標が要求するのは、まさにこの横ばいセグメントです。**
かつ10億円は国内市場全体の約1%にあたります。

§4 は「トラフィックと moat が衝突したら moat を優先し、Strategy Agent へ
エスカレーションせよ」と定めています。これはその衝突そのものです。

### 提案する解決（仮説であり、検証対象）

| 論点 | 整理 |
| --- | --- |
| 汎用AI占いアプリとして戦う | **負ける。** positioning.md の指摘は正しい |
| では何が違うのか | 実在する占術師の手法と、実際に訪れた神社の一次情報が**プロダクトの機能として入っている**こと |
| moat はどうなるか | 消えるのではなく、**人からプロダクトへ移設される**（WBS 0.2.5 / 2.1.4） |
| 検証されるのはどこか | **継続率**。一次情報が入ったアプリの3ヶ月継続率が、汎用AI占いの水準を上回るか（ゲートG3） |

この仮説が外れた場合、`positioning.md` の記述のほうが正しかったことになります。
そのときは **10億円の目標か、その到達期間のどちらかを変える**のが誠実な対応です。
仮説に合わせて証拠を曲げない、という `/AGENTS.md` の決定階層に従います。

## 7. 必要な前提条件

このモデルは以下を**前提**にしています。どれか一つでも満たされなければ成立しません。

| 前提 | 現状 | WBS |
| --- | --- | --- |
| 資本 | 未調達。MVP開発・広告・人件費に24ヶ月で数億円規模が必要 | 0.8 / 1.5 / 3.4.1 |
| 組織 | 実質1名。24ヶ月目には10〜15名規模が必要 | 2.4 / 3.4.2 |
| プロダクト | 未着手。アプリはゼロから | 1.2 / 1.3 |
| 一次情報 | **参拝記録がリポジトリに0件**。moat移設仮説の材料が存在しない | 0.7 |
| 法務 | 特商法・規約・免責文いずれも未整備 | 0.4 |
| 占術師の稼働 | 本人依存。倒れると全停止 | 4.2.1 |

**率直に言えば、この6つを24ヶ月で同時に満たす確率は高くありません。**
だからこそ WBS には5つのゲート（[`gates.md`](./gates.md)）を置き、
どの時点で「2年10億は無理」と判定するかを先に決めてあります。

到達しないことより、**到達しないと分かる時期が遅れること**のほうが損失が大きい、
という設計です。
